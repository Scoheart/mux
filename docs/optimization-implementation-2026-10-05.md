# 可靠性、读取性能与 Agent 自动化优化

实施基线为 v1.9.0。下文记录发布前的本地改造与验证；正式版本和交付状态以 GitHub Release 为准。

## 已纳入的改造

| 范围 | 实现 |
|---|---|
| 凭据恢复 | 权威 Keychain 读取返回成功／不存在／失败三种结果；失败不能成为“原先没有 Key”的回滚证据。启动迁移先做不读取密钥值的权威存在性检查。 |
| 活动计划 | Asset 计划以 OS 文件锁持有 owner lease；其他进程启动恢复保留仍在审阅的计划；结束和进程退出释放。 |
| Skills 收敛 | 中央 desired 先持久化，再按审阅过的物理目录收敛链接；按差量保留其他消费者与禁用状态，共享目录统一归一化。恢复只处理未完成目标；空变化目标不清除原有 incident。 |
| 网络与锁 | Skills 检查、MCP 刷新采用准备／锁外探测／短锁核验回写。Skills 最多 4 路并发，同 repository/ref/ETag 复用请求。 |
| 状态观察 | 主目录、别名与规范物理目录共用 TargetGraph；前端先订阅事件再做首次读取，网络更新检查不再控制订阅时机。 |
| 全局通知 | 右上角单条通知 portal 到 body，显示在 Modal 上方；可访问、可关闭、不抢初始焦点，悬停和聚焦暂停消失。 |
| 查询范围 | Core 新增 scoped inventory，CLI 按能力和 Agent 在扫描前裁剪；支持一次查询多个 Agent。 |
| 审阅与执行 | `operation review` 保持原进程，输出脱敏计划与 typed commit 模板；stdin 确认必须绑定原计划和风险 hash。 |
| 机器诊断 | 成功 JSON 包含脱敏 backend 状态；错误保留安全重试时间和确认 hash，不开放原始错误 details。 |
| 安装与版本 | 分开 runtime_detected/config_detected；插件宿主不代表插件安装。版本查询有 30 秒缓存、入口身份失效和并发合并；菜单跳过无用探测。 |
| 抓包读取 | 有界摘要缓存与 revision 增量，重复轮询只传新增／变化／删除；支持游标过期重置，读取继续核验文件身份与上限。 |
| CLI 排障 | 只读 Trace/Capture 查询复用 Core 的文件检查、分页和脱敏，不启动抓包。 |
| Trace 脱敏 | 结构化凭据与明确的文本凭据进入同一脱敏上下文；冷进程重建上下文，详情至少覆盖所在页面的学习范围，长值优先替换，避免跨页或详情暴露已识别凭据。 |
| 元数据维护 | Skills 能力只从已审计 JSON 清单派生，保留通用 evidence/path/probe 约束；README 去掉手写易过期数量。 |
| 本地化 | Agent 配置、启动字段、关键确认与校验使用显式 i18n，覆盖 Portal 弹窗。 |

CLI 用法和同进程确认协议见 [命令行指南](../website/guide/cli.md)。普通 `--dry-run` 仍是一次性预览；需要绑定原计划时使用 `operation review`。

这一轮保留 Rust Core 的统一业务入口，CLI 与 Tauri 只做适配。审阅采用同进程等待确认，是为了复用原计划与内存中的秘密草稿；没有为跨进程提交另建明文暂存机制。

## 保留的边界

- 显示缓存不参与写入授权；提交仍重新读取、核对计划和目标 CAS。
- Scoped revision 标识所选范围，不能替代完整 convergence plan 的 revision。
- 独立 Skills staging 仍按已有 24 小时规则过期；超长审阅需要重新生成计划。
- `Keep` 凭据编辑仍做可靠备份。进一步缩小备份集合需要在持久事务里定义 credential write set，不能仅跳过旧恢复契约要求的备份。
- Capture 每轮仍核对最多 5000 个摘要的文件元数据；节省的是重复 JSON 读取／解析和全量 IPC。缓存最多 4 个会话，每个会话最多 5000 条和 100 MiB 摘要输入。
- Trace JSONL 为恢复脱敏上下文，会重新读取目标之前的记录，详情还学习后续最多 59 条常规上下文；工具结果配对最多向后 1000 条。扫描总预算为 32 MiB / 100000 条，凭据集合最多 4096 项 / 合计 1 MiB / 单值 64 KiB；上下文损坏、不完整或超限时拒绝返回正文。没有将内存中的凭据集合持久化。
- Model scoped 查询仍生成公共能力元数据，实际原生配置解析按 Agent 裁剪；不承诺所有查询都严格只做单 Agent 的工作。
- 本轮没有重写 Provider manifest、给 Trace JSON 文档增加持久解析索引，也没有移除其它尚未迁移页面依赖的本地化桥。
