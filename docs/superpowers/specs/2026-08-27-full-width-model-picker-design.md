# 全宽 Model 选择器设计

## 背景与目标

新增 Model 表单当前把“协议”和“Model ID”放在同一个双列网格中。模型候选菜单只能继承右半列宽度，较长的 Model Name 和 ID 被压缩，用户难以辨认候选项。

本改动让 Model ID 独占整行，使候选菜单使用表单完整可用宽度，同时避免把所有字段改成单列后增加弹窗高度。

## 布局

- 名称与 Provider：继续使用现有双列布局。
- 协议：继续位于双列网格的左列，保持半行的紧凑宽度。
- Model ID：在同一网格中跨越全部两列，独占下一行。
- 候选列表：继续相对 Model ID 容器定位；因为容器变为全宽，列表自动扩展到完整表单宽度。
- 完整请求 URL、上下文窗口、最大输出和推理：保持现有布局。

候选项仍以 Model Name 为主信息、Model ID 为次信息、上下文长度为右侧辅助信息。选择候选只写入 Model ID，不自动覆盖用户的可选名称或 Token 配置。

## 响应式与边界

- 不扩大弹窗，不增加新的浮层或横向滚动。
- 协议字段在常规宽度保持半行；现有窄屏单列媒体规则继续让它自然恢复全宽。
- 新建与编辑 Model 共用同一表单，因此两种入口都获得全宽 Model picker。
- Provider 锁定、模型发现、手动 Model ID 输入和保存契约均不改变。

## 验收

- Model ID 容器在 `.mux-model-form-grid` 内通过 `grid-column: 1 / -1` 跨越全部列。
- 模型候选列表宽度与 Model ID 行一致，能展示更多完整的 Name 和 ID。
- 名称与 Provider 仍在同一行，协议保持紧凑，不额外增加一整列空白。
- `900×600` 和常规桌面窗口不产生横向溢出。
