# MCP 图标自定义设计

## 背景与目标

MUX 当前用 MCP 名称的首个有效字母和名称哈希颜色生成头像。大量 MCP 具有相同前缀时会形成重复字母和随机高饱和色，既不利于扫视识别，也会与“生效”等状态颜色竞争。

本功能为 MCP 提供统一的内置语义图标、自动推荐和用户自定义能力。图标只影响 MUX 展示，不进入 MCP 配置、Agent 投影或导出配置。

## 解析优先级

每个中央 MCP 资产使用稳定键 `name::transport` 关联图标偏好，并按以下顺序解析：

1. 用户上传的本地图片。
2. 用户选择的内置图标。
3. MUX 根据名称、说明、标签、命令或 URL 推荐的内置图标。
4. 无法分类时使用双字母缩写。

同一个 MCP 的来源副本共享图标偏好，因为它们代表同一个中央资产身份。图标不会表达“生效”“被覆盖”或选中状态；这些状态继续由现有徽标和卡片背景负责。

## 内置图标

首版提供 18 个本地线性图标：

- 通用 MCP
- 搜索
- 浏览器
- 文档
- 知识库
- 文件
- 数据库
- 终端
- 代码
- API
- 云服务
- 自动化
- 可观测性
- 地图
- 通信
- 媒体
- 安全
- AI

自动推荐使用确定性的关键词表，不联网、不抓取 favicon，也不把名称发送到第三方。未知名称保持双字母兜底，不强行猜测。

## 用户交互

MCP 详情 Inspector 新增“图标”操作，打开中等尺寸选择器：

- 顶部显示当前头像和自动推荐结果。
- “全部图标”以可访问按钮网格展示 18 个内置图标。
- “上传图片”打开原生文件选择器，仅允许 PNG、JPEG 和 WebP。
- 已有用户覆盖时提供“恢复自动”。
- 选择、上传或恢复成功后立即更新当前卡片与 Inspector；再次进入 Agent 页面时使用同一偏好。

选择器在 `900×600` 最小窗口内可滚动，不扩大主窗口，不向每张卡片增加常驻按钮。

## 存储与安全

图标偏好写入 Core 管理的 `~/.mux/settings.json`：

```json
{
  "ui": {
    "mcp_icons": {
      "brave-search::stdio": { "kind": "builtin", "value": "search" },
      "team-docs::http": { "kind": "custom", "value": "<sha256>.png" }
    }
  }
}
```

自定义图片复制到 `~/.mux/assets/mcp-icons/`，文件名由内容 SHA-256 和经过验证的扩展名组成。Core 执行以下约束：

- 目标 MCP 稳定键必须存在于当前中央 Registry。
- 内置图标 ID 只允许小写字母、数字和连字符，最长 32 字符。
- 上传文件不得超过 1 MiB，并以文件签名而非用户扩展名识别 PNG、JPEG 或 WebP。
- 不接受 SVG、外部 URL、目录、未知格式或不安全文件名。
- 图标目录和文件使用 MUX 私有目录/文件权限与耐久写入路径。
- 设置写入继续经过现有锁、CAS、备份、同目录临时文件和原子替换，并保留未知 UI/顶层字段。

Desktop 只通过 Core/Tauri 用例修改偏好。WebView 只可通过 Tauri asset protocol 读取 `~/.mux/assets/mcp-icons/**`，不能扩大到其他用户文件。

自定义文件缺失、损坏或无法加载时，界面回退到自动图标；MCP 功能与保存流程不受影响。

## 架构边界

- `core/src/application/ui.rs` 是偏好验证、导入和持久化用例入口。
- `desktop/src-tauri` 只负责原生文件选择器和薄命令适配。
- React 维护图标目录、关键词推荐、选择器和展示，不写配置文件。
- Agent 页面继续只能消费中央资产；它读取图标偏好，但不提供资产生命周期写操作。

## 非目标

- 不下载网站 favicon 或远程品牌 Logo。
- 不支持外部图片 URL、SVG、GIF、动画、裁剪或颜色编辑。
- 不把图标嵌入 `mcp.json`、中央 MCP catalog、Agent 配置或导出配置。
- 不为 Model、Skill 或 Agent 增加同类自定义功能。
- 不在首版清理历史未引用的内容哈希图片；它们保持私有且不会被加载。

## 验收与测试

- Core 覆盖内置选择、上传、恢复自动、未知字段保留、文件签名/大小/资产键验证、私有权限和缺失文件回退。
- Tauri 覆盖命令注册和取消文件选择不产生写入。
- React 覆盖自动推荐、双字母兜底、内置覆盖、自定义图片 URL、选择器动作以及 Registry/Agent 头像接入。
- 生产 Release 构建验证 TypeScript、Tauri、签名、App、DMG、Updater 和 CLI；本地快速交付模式不替代正式安装版做 UI 验收。
