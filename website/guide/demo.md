## 视频内容

- **Models**：中央模型卡片与 Provider 来源。
- **MCPs**：集中管理工具连接与配置。
- **Skills**：左侧来源导航、名称与三行简介卡片。
- **Provider 编辑**：修改入口 URL、模型列表 URL 与协议 Path。
- **Agent 选择器**：浏览 CLI、Desktop、IDE 与 Plugin 的卡片入口。

录制使用经过版本和签名核验的 1.10.0 App，数据是专门创建的公开示例。示例 Model ID 和端点不代表可以调用的真实服务；视频不发送模型请求。中英文字幕可在播放器中切换，也可下载 MP4。
